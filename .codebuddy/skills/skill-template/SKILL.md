## 使用方式

1. 将本目录复制为 `.codebuddy/skills/<your-skill-name>/`。
2. 替换 frontmatter 中的 `name` / `description` / `metadata`，确保 `Use when` 触发词与目标用户表述吻合。
3. 按 [目录结构](#目录结构) 填充 `assets/` 与 `references/`，并删除占位 `.gitkeep`。
4. 更新 [文档索引](#文档索引) 与 [常见场景](#常见场景)，让链接全部可点。
5. 删除本 [使用方式](#使用方式) 章节，保留落地后的成品。
